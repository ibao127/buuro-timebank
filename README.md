# buuro-timebank
This project is a student-built website for Buuro.net.

The goal is to support a neighbourhood-based timebank where people exchange time and skills instead of money (UUro).

The website is not a fully developed website, but a front-end with static pages, interactive elements, information, and a design that we developed based on the findings of our focus group discussion and vignette experiments. Our partner already has an existing back-end structure and they will integrate our design into their website in the future.
